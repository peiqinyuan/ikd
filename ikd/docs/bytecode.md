# 字节码与打包格式

ikd 编译器把每个源文件编成一个模块镜像（`ModuleImage`），再组成程序镜像（`ProgramImage`）。虚拟机按栈式指令解释执行。

## 程序镜像

序列化魔数：`IKDB`。内容包括版本、入口路径、接口表、原生函数名表、以及若干模块。

每个模块含：常量池、函数（字节码 + 行号表 + 闭包 upvalue 描述）、类、枚举、类型描述、全局槽、导出名、模块初始化函数。

## 主要操作码

见 `Ikd.Runtime.Op`：加载常量/局部/全局（含被闭包捕获的 Cell）、属性读写与调用、`super`、`new`、枚举构造与匹配、跳转、算术比较、列表/映射、迭代、`import`、`try`/`throw`、闭包创建。

## `ikd build` 的 exe

1. 复制当前 `ikd.exe`（含虚拟机）作为宿主。
2. 在文件末尾追加：压缩后的程序镜像 + 长度 + 魔数 `IKDX`。
3. 启动时若尾部能读出 `IKDX`，则直接进入 VM 运行内嵌程序，不再把第一个参数当编译器子命令（`help` / `version` 除外）。

因此用户程序 exe 可以拷到任意目录运行，不依赖源码和 .NET SDK。
