# 错误码

诊断形如：`文件(行,列): 错误[E0xxx]: 消息`，下面可能有源码行、`^` 指示和 `提示`。

## 词法 1xxx

| 码 | 含义 |
|---|---|
| E1001 | 非法字符 |
| E1002 | 未结束的字符串 |
| E1003 | 未结束的插值 |
| E1004 | 非法转义 |
| E1005 | 未结束的块注释 |
| E1006 | 非法数字字面量 |

## 语法 2xxx

| 码 | 含义 |
|---|---|
| E2001 | 意外的记号 |
| E2002 | 此处需要表达式 |
| E2003 | 此处需要类型 |
| E2004 | 此处需要标识符 |
| E2005 | 缺少某个记号 |
| E2006 | 此处需要代码块 |
| E2007 | 此处需要语句 |
| E2008 | 非法赋值目标 |
| E2009 | 此处需要模式 |
| E2010 | 重复的修饰符 |
| E2011 | 关键字位置不对 |
